# VEDA v0.3.1 — Hierarchical Resolution + Opportunistic Planning Challengers

**Release status:** Experimental challenger release built on v0.3.0 Adaptive ExecutionRank.  
**Resolver safety:** EngineeringRank + Adaptive ExecutionRank remain the established production path. TreeRank is promoted as a first-class experimental hierarchy expert; Rescheduler remains an experimental planning/state-transition expert and is **not** the default identity resolver.

## Why v0.3.1 exists

v0.3.0 showed that live execution context can rescue observations whose physical identity is weak, but also that globally applying WorkfrontRank damages strong WBS/hierarchical cases. v0.3.1 investigates two new structural ideas against the same large adversarial schedules:

1. **TreeRank** — resolve an observation by asking *where in the schedule/WBS hierarchy it belongs*, using parent/child/sibling/ancestor context and relation/granularity reasoning.
2. **Rescheduler** — perform opportunistic/continual planning: after new evidence changes the believed project state, evaluate feasible local continuations and use counterfactual plan coherence as a specialist signal.

## TreeRank

TreeRank keeps a hierarchy-native schedule model containing parent, child, sibling, ancestor and descendant relationships plus phase, discipline, location, action, asset and date evidence. It has an independent hierarchy candidate-generation channel so a correct branch does not need to appear in SemanticRank's initial shortlist.

It also emits granularity/relation hypotheses such as `AGGREGATES`, `PART_OF`, `SPLIT_ACROSS` and `NEW_SCOPE`.

### Frozen TEST ranking

| Resolver | Top-1 | R@3 | R@5 | R@10 | MRR |
|---|---:|---:|---:|---:|---:|
| SemanticRank | 44.44% | 54.44% | 60.00% | 83.33% | 0.5404 |
| EngineeringRank | 60.00% | 77.78% | 90.00% | 94.44% | 0.7116 |
| WorkfrontRank | 61.11% | 84.44% | 90.00% | 95.56% | 0.7281 |
| **TreeRank** | **58.89%** | **92.22%** | **94.44%** | **100.00%** | **0.7680** |
| Rescheduler | 48.89% | 77.78% | 91.11% | 91.11% | 0.6652 |

TreeRank's strongest frozen TEST categories were WBS, phase, temporal and hard-negative cases, each at **100% Top-1**. It intentionally scored 0% on the legacy workfront category because it has no live execution-history signal.

### Mixed holdout

Against the 180-case / 13,436-activity mixed holdout, TreeRank achieved **65.58% Top-1** on 154 UID-labelled cases and **69.44% Top-1** on 144 exact links, slightly above the existing v0.3.0 Adaptive ExecutionRank on those two metrics.

The strongest evidence for TreeRank is the 64-case mixed adversarial block, where it reached **75.00% Top-1**, versus 59.38% for the existing two-expert Adaptive ExecutionRank.

### Granularity limitation

Across DEV, TEST and mixed holdout, TreeRank relation accuracy was:

| Relation | Accuracy |
|---|---:|
| AGGREGATES | 100% |
| NEW_SCOPE | 100% |
| SPLIT_ACROSS | 100% |
| PART_OF | 0% |
| Overall non-EXACT | 72.22% |

The current hierarchy does not yet solve the important case where field execution is *finer than the scheduled leaf*. A future version should allow **virtual/latent execution children** beneath coarse scheduled nodes and connect them to the Reality Graph.

## Rescheduler

Rescheduler is a lightweight opportunistic-planning / plan-recognition experiment. It uses indexed evidence-directed screening followed by counterfactual local state updates and short rolling-horizon beam search over disputed candidates.

Its role is not to replace EngineeringRank. It asks a different question: *if this observation is true, which local changed-world interpretation creates the most coherent feasible continuation?*

### Key result

Rescheduler is weak as a universal identity resolver but strong as a live-workfront specialist:

- Frozen TEST overall Top-1: **48.89%**
- Frozen TEST workfront Top-1: **100.00%**
- Mixed holdout workfront Top-1: **87.50%**

It fails when a strong WBS/phase identity should dominate a more attractive future plan (0% WBS and phase Top-1 on frozen TEST). This confirms that physical observation evidence must remain authoritative; planning coherence is specialist evidence, not schedule truth.

## Conservative tie-aware evaluation

The challenger harness uses tie-aware ranking. If the expected candidate receives exactly the same score as indistinguishable alternatives, it receives the **worst rank in the tie group**. Deterministic insertion/UID order cannot manufacture Top-1 accuracy.

## Architecture conclusion

v0.3.1 does **not** replace VEDA with a Tree or planner. The evidence supports a multi-expert direction:

```text
Observation
   |-- EngineeringRank  : physical/semantic identity
   |-- TreeRank         : hierarchy + granularity
   |-- WorkfrontRank    : live execution-state prior
   '-- Rescheduler      : state transition / local continuation
              |
              v
     learned contextual routing
              |
              v
          Reality Graph
              |
              v
  deterministic validation / review
```

A future learned gate should decide expert authority from measurable context rather than hardcoded category rules. Rescheduler is a particularly strong candidate for use **after** canonical event resolution, where it can adapt the near-term plan to newly observed reality.
