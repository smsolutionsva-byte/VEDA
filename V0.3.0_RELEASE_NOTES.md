# VEDA v0.3.0 — Adaptive ExecutionRank

## Why this release exists

The v0.3 WorkfrontRank experiment showed a real but conditional advantage: live execution topology rescued under-specified observations, but an always-on graph prior damaged cases where engineering identity (WBS, location, phase, asset, date) was already strong.

v0.3.0 therefore changes the architecture from **fixed fusion** to a **learned query-level expert gate**.

## Core architecture

Two resolver experts remain independent:

1. **EngineeringRank** — semantics + engineering identifiers + action + phase + location + WBS + temporal + relationship context.
2. **WorkfrontRank** — dynamic execution frontier + recent workfront state + predecessor/successor plausibility + local Personalized-PageRank-style graph coherence.

`AdaptiveExecutionGate` observes the evidence and the shape of disagreement between both experts, then selects which expert should have authority for that query.

The gate does **not** receive benchmark category names or rules such as `if WBS -> Engineering`.

### Gate inputs

Examples include:

- evidence asset/location/action/phase completeness;
- EngineeringRank top score, margin and top-k entropy;
- WBS/location/asset/temporal/graph discriminative spread across candidates;
- execution-frontier concentration and entropy;
- WorkfrontRank margin, PPR and frontier-channel strength;
- degree of disagreement between the two experts.

The runtime model is a transparent standardized logistic gate exported to JSON. Training uses scikit-learn, but production inference does not require scikit-learn.

If the model artifact is missing or incompatible, VEDA safely falls back to **EngineeringRank**.

## Training hygiene

The gate was trained only on the original Goose **DEV** split. There were 90 UID-labelled DEV rows usable for expert-utility training.

Five-fold out-of-fold DEV results:

| Variant | Top-1 |
|---|---:|
| EngineeringRank | 62.22% |
| Always-on WorkfrontRank | 62.22% |

### Critical category behavior

- WBS: Engineering **83.33%**, Workfront **16.67%**, Adaptive **83.33%**.
- Missing-identity workfront: Engineering **25.00%**, Workfront **68.75%**, Adaptive **68.75%**.
- Phase: Adaptive **100%**.
- Temporal: Adaptive **100%**.
- Hard same-asset/wrong-action negatives: Adaptive **100%**.

This is the intended outcome: Workfront authority is learned from context instead of globally applied.

## Research basis

The architecture is consistent with three relevant ideas:

1. **Mixture/expert gating**: dynamically assign authority to specialized experts instead of forcing a universal model.
2. **Graph-aware entity linking**: Personalized PageRank can use domain-graph coherence to disambiguate locally similar entities.
3. **Construction sequence context**: predecessor/successor context has been shown to improve construction schedule activity classification beyond text alone.

The gate probability is an **expert-routing propensity**, not a calibrated probability that the chosen activity is correct. Activity-match calibration remains a separate VEDA layer.
