Privacy

VEDA Anywhere is a bridge, not a monitor. It is disabled by default and does nothing until you explicitly select text and invoke VEDA.

  • Never continuously monitors or reads web pages
  • Never scrapes page content or collects browsing history
  • Never inspects chat messages or watches keyboard input
  • Never auto-sends selected text, URLs or page contents
  • No background AI analysis of any page

During normal browsing, VEDA receives nothing.

VEDA backend

Where your VEDA app is running. The default is http://127.0.0.1:8770. Change this only if you started VEDA on a different host or port.

Website access

Website access, the active project and the on/off switch are managed in the VEDA app so they stay consistent with your account. This keeps one source of truth.
