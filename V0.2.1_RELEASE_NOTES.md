# VEDA v0.2.1 — Engineering Resolution Upgrade

This snapshot packages the engineering-aware schedule entity-resolution work discussed for OIL/SIH26122.

## Major changes

- Hybrid activity retrieval with dense embeddings, BM25, BGE-M3 native sparse support, exact engineering entities, fusion and optional cross-encoder reranking.
- Canonical asset/entity extraction with safe aliases and OCR-probable aliases.
- Activity event-state separation: start, progress, finish, blocked/no-progress, planned future, correction/cancelled and mixed observations.
- Structured WBS hierarchy reasoning, lifecycle/phase context, location hierarchy and Primavera source-ID/display-ID fallback.
- Explicit temporal features using baseline/current/actual context, corroboration and soft stale-plan handling.
- Predecessor/successor graph features across FS/SS/FF/SF, lag, driving state and out-of-sequence handling.
- Engineering reranking separated from retrieval score, calibrated probability and action policy.
- Risk policy separated from production linking; no hidden linker threshold literals.
- Canonical execution-event and source-corroboration schema, plus activity lineage support.
- Agent/MCP surfaces for hybrid search, activity context, resolution planning, calibration diagnostics and historical-sequence advice.
- Persistent/warm retrieval index behavior and batch-oriented linking path.
- Frozen 382-case adversarial benchmark with SHA-256 verification and semantic integration audit.
